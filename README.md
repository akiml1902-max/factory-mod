# Factory Mod — Minecraft 1.20.1 Forge

Мод добавляет отдельную вкладку креатива **Factory**.
В ней есть блоки быстрой постройки:

- Factory Builder Block — завод
- Oil Rig Builder Block — нефтевышка
- Power Plant Builder Block — электростанция
- Quarry Builder Block — карьер
- Warehouse Builder Block — склад
- Greenhouse Builder Block — теплица

## Как работает

1. Зайди в креатив.
2. Открой вкладку **Factory**.
3. Возьми нужный блок постройки.
4. Поставь блок на землю.
5. Нажми ПКМ по блоку — вокруг него построится здание.
6. Внутри здания будет сундук.
7. В сундук раз в некоторое время падают припасы.
8. Если сломать главный блок постройки, доход прекращается.

## Предметы добычи

- Steel Ingot / Стальной слиток
- Crude Oil Canister / Канистра сырой нефти
- Machine Parts / Детали механизма
- Copper Wire / Медная проводка
- Stone Crate / Ящик камня
- Supply Crate / Ящик припасов
- Fertilizer Bag / Мешок удобрений
- Energy Cell / Энергоячейка

## Сборка .jar через GitHub без установки программ

1. Создай новый репозиторий на GitHub.
2. Загрузи все файлы из этой папки в репозиторий.
3. Открой вкладку **Actions**.
4. Выбери **Build Forge 1.20.1 Jar**.
5. Нажми **Run workflow**.
6. После завершения сборки скачай файл из **Artifacts**.
7. Внутри архива будет готовый `.jar` для папки `mods`.
